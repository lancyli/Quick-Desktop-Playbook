场景概述

🔴 传统月末结账的四大痛点

⏱️

耗时漫长

手动从 ERP 导出数据，Excel 逐行比对银行流水，反复核对差异。一轮完整对账需 3-5 个工作日。

❌

差错率高

人工比对容易遗漏、错行、误判。尤其是摘要不一致的交易，差错率高达 5-10%。

👥

人力浪费

出纳、会计、主管 2-3 人协作，反复沟通确认差异项，高学历财务人员做低价值重复劳动。

📊

报告滞后

对账完成后还需手工做 Word/PPT 报告，逐个发邮件给管理层。报告出炉时数据已失去时效性。

✅ 目标：Quick Desktop 将全流程压缩到 30 分钟以内

通过 Amazon Quick Desktop 的连接器生态 + Python 沙箱 + 多格式文档生成 + 定时任务能力， 构建一条从「外围系统数据采集」到「管理层收到报告」的全自动流水线。 财务主管只需说一句 "开始本月对账"，即可一键触发全流程。

7 步全流程详解

📥

数据采集 — 从 OneDrive / SharePoint 拉取 ERP 报表

财务人员将 ERP 导出的总账明细、银行对账单上传到 OneDrive 的固定目录。Quick Desktop 通过 OneDrive 连接器自动感知新文件并拉取到本地。

操作示意：
• 调用 amazon_onedrive__ListChildren 扫描 /财务月末数据/202608/ 目录
• 调用 amazon_onedrive__GetItem 下载 Excel/CSV 文件到本地
• 自动识别文件类型（ERP 导出 vs 银行对账单 vs 应收应付）
涉及能力
☁️ OneDrive 连接器 📂 SharePoint 连接器 📁 本地文件系统
2
📧

邮件附件提取 — 从 Outlook 获取银行回单 PDF

银行每月末通过邮件发送回单。Quick Desktop 通过 Outlook 连接器搜索特定发件人的邮件，自动下载附件中的 PDF 并解析为结构化数据。

操作示意：
• 调用 email_search 搜索 subject:"银行回单" AND from:"bank@xxx.com"
• 下载 PDF 附件 → file_read_pdf 提取文本
• LLM 解析非结构化回单文本为标准化 JSON
涉及能力
📬 Outlook 连接器 📄 PDF 解析 🤖 LLM 文本理解
3
⚙️

数据清洗 + 自动对账 — 三维度智能匹配

在 Python 沙箱中加载多源数据，执行三维度自动对账：参考号精确匹配 → 日期+金额模糊匹配 → 摘要相似度匹配。自动标记匹配结果和差异项。

对账逻辑：
• Level 1：参考号精确匹配（PZ-xxxx ↔ BK-xxxx）
• Level 2：日期 ± 3天 + 金额 ± 1% 容差匹配
• Level 3：difflib.SequenceMatcher 摘要相似度 ≥ 0.6
• 输出：matched / erp_only / bank_only 三类清单
涉及能力
🐍 Python 沙箱 📊 pandas 🔍 difflib 模糊匹配 📁 run_python
4
📊

智能分析 + 可视化 — 生成交互式仪表盘

基于对账结果和财务数据，自动生成包含 6+ 图表的交互式 HTML 仪表盘。支持点击钻取、筛选、悬浮详情等交互。

仪表盘内容：
• KPI 卡片：对账匹配率 · 未匹配数 · 应收逾期 · 应付逾期 · 资金余额
• 银企对账结果饼图 · 账龄分布柱状图 · 资金走势折线图
• 部门费用分布 · 供应商 Top10 · 未匹配明细表
涉及能力
📈 Highcharts 🎨 HTML 构建 🐍 Python 数据处理
5
📄

报告生成 — Word / PPT / PDF / Excel 多格式输出

一键生成 4 种格式的输出物：管理层 Word 报告（含图表和关键发现）、PPT 演示文稿、PDF 归档版、Excel 对账明细。

输出物：
• 📝 Word 报告：管理层月末财务简报（摘要 + 图表 + 建议）
• 📊 PPT 演示：CFO 月度汇报用幻灯片
• 📕 PDF 归档：含审计轨迹的正式版本
• 📗 Excel 明细：匹配/未匹配/差异的完整清单
涉及能力
📝 canvas_docx 📊 canvas_pptx 📕 canvas_pdf 📗 canvas_xlsx
6
🚀

审批推送 — Teams 通知 + Outlook 邮件分发

对账完成后，自动通过 Teams 发送摘要通知给 CFO，同时通过 Outlook 发送完整报告邮件（附件含 PDF + Excel）。差异项自动创建待办。

推送逻辑：
• Teams: "@CFO 本月对账完成，匹配率 96%，3 笔差异待确认 [查看仪表盘]"
• Outlook: 正式邮件 + PDF报告附件 + Excel明细附件
• 差异项 → 自动生成 To-do 待办（含截止日期）
涉及能力
💬 Teams 连接器 📬 Outlook 连接器 ✅ 待办 (To-do)
7
⏰

定时自动化 — 每月末自动触发全流程

通过 Quick Desktop 的 Schedule 功能，设置月度定时任务。每月最后一个工作日上午 9:00 自动启动对账 Agent，无需人工干预。

配置示意：
• 触发规则：每月最后一个工作日 09:00
• 任务 Agent：「月末财务对账助手」
• 启动指令："执行 2026 年 8 月财务月末对账全流程"
• 结果通知：完成后通过 Activity Feed 推送
涉及能力
⏰ Schedule 定时任务 🤖 Agent 自动执行 📰 Activity Feed
